# prompts-proyecto-averias

Prompts del proyecto de Claude «Averías GarantiPlus — copiloto del técnico». Versión v5.1 (2026-11-23).

- `instructions.md`: las instrucciones del proyecto. `01-mecanica-siga.md`, `02-casos-referencia.md`, `05-redaccion-informes.md`, `06-documentos-de-pago.md` (la segunda línea de trabajo, v5.0: checklist de pago, cómo reconocer cada documento, casos reales y catálogo de comentarios), `casos-garantiplus.md`, `casos-mitsubishi.md`, `contrato-mitsubishi.md`: los recursos de Conocimiento.
- `comunicados/`: comunicados del área que fijan criterio (`2025-07-04-mantenimiento-seminuevos-alta-gama.md`: seminuevos M2 de BMW, Audi, Mercedes-Benz, Jaguar, Land Rover y Volvo con el plan del fabricante desde la vigencia).
